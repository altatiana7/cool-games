# Cool games

Игры и тренажёры по английскому. Главная страница: `index.html`, игры лежат в папке `games/`.

Список игр на главной хранится в `games.json`. Загружать, менять и удалять игры и любые файлы можно на странице `admin.html` (значок шестерёнки в шапке главной) — нужен ключ GitHub с правом Contents: Read and write.

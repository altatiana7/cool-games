Подключение

Чтобы загружать и удалять файлы прямо с сайта, нужен ключ доступа GitHub. Он делается один раз и хранится только в этом браузере.

  1. Откройте страницу создания ключа на GitHub (войдите под altatiana7).
  2. Token name — например, cool-games. Expiration — выберите срок (можно No expiration или 1 год).
  3. Repository access → Only select repositories → выберите cool-games.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Нажмите Generate token, скопируйте ключ (начинается с github_pat_) и вставьте ниже.
